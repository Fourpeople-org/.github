# fourpeople-org

Bienvenido a **fourpeople-org**, una organización en GitHub creada como parte de la materia **Trabajo en Equipo**, dictada por el profesor **Luwig Buitrago**.  

## Propósito
Este espacio fue diseñado para:
- Fomentar la colaboración entre los integrantes del grupo.  
- Practicar metodologías de trabajo en equipo aplicadas al desarrollo de software.  
- Organizar proyectos, tareas y entregas de manera centralizada.  

## Estructura
Dentro de la organización encontrarás diferentes repositorios, cada uno enfocado en actividades, prácticas o proyectos relacionados con la materia.  

## Herramientas de colaboración
- **Issues**: para el seguimiento de tareas y problemas.  
- **Pull Requests**: para revisión y discusión de cambios antes de integrarlos.  
- **Projects**: para la planificación visual del trabajo en equipo.  

Esta organización refleja el compromiso de sus integrantes con el aprendizaje colaborativo y la práctica de buenas metodologías de desarrollo.
